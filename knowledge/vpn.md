# VPN Troubleshooting

## Problem
The user cannot connect to the organization's VPN.

## Troubleshooting Steps

1. Confirm that the device has an active internet connection.
2. Check that the official VPN client is installed and running.
3. Restart the VPN application.
4. Confirm that the user is using the organization's approved VPN server or profile.
5. Check whether the VPN client displays an error message.
6. Restart the device if appropriate.
7. Try connecting again.
8. If the connection still fails, contact IT support.

## Security Notes

- Never ask users to provide their VPN password.
- Never request MFA codes.
- Do not disable endpoint security software to troubleshoot VPN problems.
- Do not install unofficial VPN software.
- Do not change VPN security settings without authorization.

## Escalation

Create an IT support ticket if:

- The VPN continues to fail.
- The VPN account appears locked.
- The VPN server appears unavailable.
- Multiple users are experiencing the same problem.
