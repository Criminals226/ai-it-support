# Password and Account Troubleshooting

## Problem
The user cannot log in or has forgotten their password.

## Troubleshooting Steps

1. Confirm that the user is entering the correct username.
2. Check whether Caps Lock is enabled.
3. If the password has been forgotten, use the organization's approved password-reset procedure.
4. If the account is locked, contact the IT support team.
5. After resetting the password, sign in again using the organization's approved authentication process.

## Security Rules

- Never ask users to send their password.
- Never ask users to provide MFA codes.
- Never store passwords in plain text.
- Never bypass authentication controls.
- Do not disable security controls to resolve login problems.

## Escalation

Create an IT support ticket if:

- The account remains locked.
- Password reset fails.
- The user cannot complete the approved authentication process.
- There is a suspected account compromise.
