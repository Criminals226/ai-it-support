# Printer Troubleshooting

## Problem
The user cannot print a document.

## Troubleshooting Steps

1. Check that the printer is powered on.
2. Confirm that the printer is connected to the organization's network.
3. Check whether the printer displays an error message.
4. Check whether the correct printer is selected.
5. Cancel stuck print jobs if authorized.
6. Restart the printer if appropriate.
7. Restart the user's computer if necessary.
8. Try printing a test document.
9. If the problem continues, contact IT support.

## Security Notes

- Do not install unknown printer drivers or software.
- Use only organization-approved printer software.
- Do not modify network settings without authorization.

## Escalation

Create an IT support ticket if:

- The printer remains unavailable.
- The printer displays a hardware error.
- Multiple users cannot print.
- The printer requires administrator-level configuration.
