# Wi-Fi Troubleshooting

## Problem
The user cannot connect to Wi-Fi or is connected but has no internet access.

## Troubleshooting Steps

1. Check that Wi-Fi is enabled on the device.
2. Confirm that the user is connected to the correct Wi-Fi network.
3. Disconnect from the network and reconnect.
4. Restart the device.
5. Check whether other devices can access the internet.
6. If other devices also cannot connect, the issue may be related to the router or network service.
7. If only one device is affected, check the device's network settings.
8. If the problem continues, contact IT support.

## Security Notes

- Never ask the user for their Wi-Fi password.
- Do not ask the user to disable security software unless authorized IT staff instruct them to do so.
- Do not make administrator-level network changes without authorization.

## Escalation

Create an IT support ticket if:

- The problem continues after basic troubleshooting.
- Multiple employees are affected.
- The network appears to be unavailable.
